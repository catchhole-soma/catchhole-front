# Pencil 활성 화면 동기화 트래킹

`design/catchhole.pen`은 CatchHole Front의 실제 브라우저 화면을 기준으로 유지하는 디자인 기준 파일이다. 활성 화면은 `Active / ...` 루트 프레임으로 구분하고, 현재 Front에 연결되지 않은 Post-MVP 시안은 별도 Presentation 영역에 그대로 보존한다.

### 2026-09-06 모바일 조작 방식 보완

`mobileUx20260906` 보드에 320px 브라우저 캡처를 동기화했다. 모바일 대시보드 탭·검토 필터는 선택 메뉴로, 업로드 단계는 번호/라벨의 세로 구성으로 바뀐다. 세계관 직접 입력은 한 열 폼과 고정 저장 영역, 캐릭터 상세는 실제 header 높이에 맞춘 본문 스크롤을 사용한다. 데모 헤더는 전체 브랜드와 한 줄 나가기 버튼을 유지한다. 사용자 교정에 따라 데모 진입·새 화면·재체험은 맨 위에서 읽기 시작하고, 안내 대상과 화면 회전에 의한 자동 스크롤은 제거했다. 캡처의 데모 상태도 맨 위로 갱신했다. 실제 기기/Safari 검증을 완료했다는 의미는 아니다.

- 기준 화면 크기: 데스크톱 `1440×900`, 모바일 `390×844`
- 동기화 대상: `/landing`, `/login`, `/signup`, `/demo`, `/terms`, `/privacy`, `/works`, `/dashboard`, `/editor`, `/episode-upload`, `/setting-review`, `/episode-validation-report`
- 함께 관리하는 상태: 접근 가능한 모달·서랍·토스트, 로딩·빈 화면·오류, 제출·저장·분석·재시도, 토큰 중단·재개
- 제외 대상: `/chat`, `/loading`, `/report` 및 현재 `/works`로 리다이렉트되는 미래 화면
- NVM-303의 `/terms`, `/privacy`, 회원가입 법률 문서 상태는 Front·Backend API와 Pencil을 함께 변경하고, 실제 문서 원문·현재 버전은 Backend `legal_documents`를 런타임 기준으로 사용한다.

### 인터랙티브 데모

- `/demo`는 로그인 없이 진입하며, 예시 원고와 사전 계산된 fixture만 사용한다.

- 분석은 실제 회차 업로드 화면과 같은 처리 단계·상태명·`설정 후보 검토` CTA를 사용한다.
- 후보 검토에서 실제 화면과 같은 이름의 `모두 확정`(캐릭터·세계관 각 묶음 하나), `수정`, `수정안 적용`, `제외`를 직접 수행하며 존재하지 않는 보조 기능은 추가하지 않는다.
- 코치마크는 화면 전체를 어둡게 가리지 않고 한 번에 하나의 다음 행동만 안내한다. 대상 바깥 윤곽선은 글자를 덮지 않으며, 코치마크 아래의 실제 화면 조작도 막지 않는다. 현재 안내와 무관한 캐릭터·근거·이력을 열어도 문구와 단계는 바뀌지 않는다.

- 완료 화면의 `내 작품으로 시작하기`는 `/signup`으로 현재 히스토리를 대체하고, 회원가입 모달 X는 데모를 다시 마운트하지 않고 `/landing`으로 이동한다.
