# 장르별 세계관 이미지 확장 리포트

작성일: 2026-09-16 · 상태: 전체 장르 제작과 서비스 연결·개발 S3 업로드 완료. 최신 구현·검증·배포 범위는 [장르 이미지 연결](world-image-themes.md)을 따른다. 아래 내용은 제작 전후 기획 기록이며 추출 프롬프트는 변경하지 않는다.

사용자 결정: **로맨스·코미디·일상·기타는 `modern-common` 테마와 이미지 종류를 공유**한다. 이 공통 테마부터 새 이미지 18장과 기존 그림의 재사용 조합을 제작했다. [첫 테마 제작 결과](world-image-modern-common.md)에서 초기 8칸·기본 7칸·추천 도감 구성을 확인할 수 있다. 아래 전체 후보 40개는 최초 공백 조사이며, 현재 제작 완료 수량을 뜻하지 않는다.

후속 제작: [무협 테마](world-image-wuxia.md)는 기본/전체 5장과 도감 27종, 총 **32장**을 제작했다. 기존 추천 23종과 추가 기존 20종을 모두 포함한 무협 선택 도감 70종, 초기 8칸·기본 7칸 매핑을 정리했다. 최초 무협 보강 후보 8개에서 조직·생활 공간·무공·물건·제도로 확대한 결과다.

후속 제작: [SF 테마](world-image-sf.md)는 새 이미지 **32장**, 신규 도감 27종과 기존 43종을 합친 **선택 도감 70종**, 초기 8칸·기본 7칸 구성을 완료했다.

후속 제작: [추리 테마](world-image-mystery.md)는 새 이미지 **25장**, 신규 도감 21종과 기존 40종을 합친 **선택 도감 61종**, 초기 8칸·기본 7칸 구성을 완료했다. 현대 공통과 고전·초자연 소재를 함께 활용한다. 기타는 사용자 결정에 따라 일상과 동일한 현대 공통 테마를 사용하므로 추가 제작하지 않는다. 장르별 이미지 준비와 서비스 연결은 완료됐다.

후속 제작: [호러 테마](world-image-horror.md)는 새 **18장**, 신규 14종 + 기존 66종의 **선택 도감 80종**을 구성했다. [스포츠 테마](world-image-sports.md)는 새 **32장**, 신규 28종 + 기존 28종의 **선택 도감 56종**을 구성했다. 두 테마 모두 초기 8칸·기본 7칸과 개별 제작 보고서를 완료했으며 실제 서비스 연결은 후속 작업이다.

## 1. 제안의 중심

**기존 333종을 공용 도감으로 유지하고, 작품 장르에 어울리는 그림을 먼저 보여준다. 새 그림은 현대 생활·조직·제도, 동양 건축·인물 구도, 미래 시설·장비처럼 현재 표현이 부족한 곳에 집중한다.**

장르마다 도감을 복제하거나 10개 장르 × 모든 대상을 다시 제작할 필요는 없다. 숲은 여러 장르가 공유하고, 중력·시간·염동력의 그림도 판타지와 SF가 공유할 수 있다. 같은 개념을 공유할 수 있어도 그림의 옷·건물·도구가 맞지 않으면 다른 배경의 버전을 추가한다.

이번 기획의 고정 조건은 다음과 같다.

- `RACE`, `FACTION`, `LOCATION`, `MONSTER`, `POWER_SYSTEM`, `WORLD_RULE_HISTORY`, `IMPORTANT_ITEM`의 **7개 enum과 의미를 유지**한다. `전체`는 탐색용 카드다.
- LLM 추출·비교 프롬프트, 대상 자동 분류와 세계관 자동 이미지 매칭은 이번 범위에 넣지 않는다.
- 이미지의 추천·검색·직접 선택을 개선한다. 사용자 업로드와 수동 선택을 우선하며 장르 변경으로 덮어쓰지 않는다.
- 분류 이름 조정은 의미가 같은 범위에서만 검토한다. 선수·학생을 종족, 범인·라이벌을 몬스터로 바꾸어 넣지 않는다.
- 코미디·로맨스·추리는 시대나 배경을 확정하지 않는다. 표 아래의 장르별 배경은 **기본 추천 방향**이며 작품의 사실에 대한 판정이 아니다.

## 2. 확인한 현재 자산과 중요한 연결 차이

서비스 등록 기준은 Backend의 `catalog-v1.json`과 V56 seed다. 제작 폴더의 일부 `service_integration` 문구는 제작 당시 상태가 남아 있어 현재 연결 여부의 근거로 쓰지 않았다.

| 분류 | 개별 도감 수 | 현재 강점 | 주요 공백 |
| --- | ---: | --- | --- |
| 종족 | 33 | 인간·엘프·수인·마족·정령·동양 설화 존재 | 미래 지성 종족, 배경에 덜 묶인 인간 표현 |
| 세력 | 40 | 국가·가문·길드·군대·종교·비밀 조직 | 현대 회사·학교 조직·수사 조직·병원·스포츠 팀·우주 조직 |
| 장소 | 30 | 자연 지형, 중세 정착지·시설 | 현대 생활 공간·경기 시설·동양 건축·우주 시설 |
| 몬스터 | 60 | 야수·언데드·괴물·골렘·환수 | SF 생물·기계 위협, 일부 현대 괴담 표현 |
| 마법·능력 | 50 | 속성·회복·내공·검기·공간·시간·중력·정신 효과 | 동양 인물 구도, 기술 장비와 작동이 함께 보이는 SF 변형 |
| 규칙·역사 | 40 | 법률·계약·신분·혼인·제례·전쟁·조약·재건 | 현대 법·학교·리그·조직 규정의 시각적 표현 |

| **합계** | **333** | 기존 자산을 먼저 활용 | 장르별로 전량 재제작하지 않음 |

별도로 초기 분류 화면 8장, 새로 제작한 분류 기본 그림 7장, 캐릭터 공통 기본 그림 1장이 있다. 제작 후 취소한 인간 1인 초상은 사용 자산에서 제외한다.

**연결 상태 확인:** 등록 도감 340행은 개별 333종 + 기본 7행이다. 그런데 이 기본 7행의 `source`는 현재 `src/assets/world-categories/*.webp`, 즉 초기 분류 그림이다. `design-assets/world-defaults/2026-09-15-v1/`의 별도 기본 그림 7장은 현재 manifest/seed에 연결되어 있지 않다. 예를 들어 등록된 몬스터 기본 그림은 그리핀이지만 별도로 제작한 최신 기본 그림은 안개에 가린 괴물이다. V60에서 두 용도의 자산을 구분해 연결했다. 이 문단은 초기 조사 시점의 차이를 기록한 것이다. 운영 DB·S3의 별도 수동 변경 여부는 이번 문서 조사에서 확인하지 않았다.

조사 범위: 개별 333종 전체 이름·제작 방향·현재 파일 색인, 기본 그림 7종 색인, 등록 manifest와 enum/추출 기준을 확인했다. 등록 자산·분류 화면 47개 표시 사례와 별도 기본 원본 3종을 시각 점검했다. 아래의 재사용 평가는 기획 판단이며 333종 전체의 최종 시각 승인이나 실제 작품 데이터에 대한 커버리지 측정은 아니다. 전체 목록과 현재 파일 경로는 [자산 인벤토리](world-image-genre-inventory.md)에 기록했다.

## 3. 장르보다 작은 단위로 공유하기

하나의 그림은 여러 장르에서 사용할 수 있다. 관리할 때는 다음 정보를 분리하는 것이 좋다.

| 판단 축 | 예 | 쓰임 |
| --- | --- | --- |
| 대상 개념 | 숲, 내공, 중력, 계약, 책 | 무엇을 표현하는 그림인지 |
| 배경·시대 | 자연, 서양 고전, 동양 고전, 현대, 미래 | 건물·옷·물건이 작품 분위기와 맞는지 |
| 분위기 | 밝음, 차분함, 긴장, 음산함 | 동일 소재 안에서 어느 그림을 먼저 보여줄지 |
| 추천 장르 | 무협·판타지, SF·판타지 등 복수 | 기본 도감 목록의 우선순위 |
| 용도 | 초기 분류 카드, 미지정 기본 그림, 개별 도감 | 구체적으로 묘사해도 되는 범위 |

예를 들어 `중력 조작`은 개념은 하나이고 판타지·SF 모두 추천할 수 있다. 그 그림에 폐허가 보이는 것은 허용 가능한 분위기인지 검토할 조건이다. `기·내공`의 동양 수련 장면은 무협 우선으로 두고 동양 판타지에서도 노출한다. `일반 서적`은 전 장르에서 검색할 수 있게 하되 현재 가죽 장정·황동 소품이 강조된 버전은 고전 배경에서 먼저 보여준다.

### 도감 화면의 제안

1. 현재 분류 안에서 `추천 이미지`를 기본으로 연다. 장르에 잘 맞는 그림과 공유 가능한 그림을 함께 보여준다.
2. `전체 도감`으로 같은 분류의 기존 그림을 모두 찾을 수 있게 한다. 장르가 다르다는 이유로 저장을 금지하지 않는다.
3. 검색 결과가 적으면 전체 도감으로 넓힐 수 있다는 안내를 제공한다. 엄격한 장르 필터로 결과를 숨기지 않는다.
4. 새 테마가 없으면 중립 기본 그림을 사용한다. 장르 미지정·미지원 상태가 곧 판타지를 뜻하지 않게 한다.

여기서 추천은 미리 등록한 태그·순서로 가능하다. 작품 본문을 새로 해석하거나 이미지를 LLM으로 판단할 필요가 없다.

## 4. 장르 × 분류의 큰 그림

**재사용:** 기존 그림을 중심으로 구성 가능. **보강:** 개념은 있지만 배경·옷·도구가 맞지 않는 곳을 보완. **추가:** 현재 도감에 대표 소재가 부족. **유지:** 해당 장르에서 억지로 채우지 않고 공통 기본과 기존 도감 접근을 유지. 모두 추천 방향이며 장르별 출현 빈도를 실측한 값은 아니다.

## 5. 기존 그림을 어떻게 재활용할지

### 장소 30종: 13종 자연 지형은 공통 기반

**공유 우선 13종:** 숲, 산·산맥, 평원·초원, 사막, 설원, 늪, 동굴, 협곡, 화산, 강, 호수, 바다, 섬. 장르 제한 없이 검색·선택 가능하게 하고, 원문에 맞는 지형일 때 추천한다. SF라고 모든 장소를 우주로, 일상이라고 모든 장소를 도시로 바꾸지 않는다.

**배경을 확인할 나머지 17종:** 마을, 도시, 성, 요새, 궁전, 신전·사원, 마탑, 학원, 길드 회관, 여관·주점, 시장, 항구, 광산, 미궁, 유적, 무덤·묘지, 이공간.

이 17종도 여러 장르에서 쓸 수 있다. 현대 추리 속 고성, 로맨스의 유적 여행, SF 행성의 고대 유적은 현재 그림이 어울릴 수 있다. 다만 현재 도시를 현대 도심으로, 학원을 현대 교실로, 범선 항구를 우주항으로 무조건 공유하면 맞지 않는다. **기존 장소는 보존하고 부족한 시대·시설 버전을 추가**한다.

| 기·내공 (`power-system-qi`) | 무협·동양 판타지 우선 | 이미 동양 복식과 수련당이 있어 신규 제작 우선도가 낮음 |
| 오러·검기 (`power-system-aura`) | 판타지 유지, 무협 검색·선택 허용 | 검기 개념은 공유 가능하지만 서양 갑옷 인물이 커서 동양 구도 보강 후보 |
| 시간·중력·염동력 (`time-magic`, `gravity`, `telekinesis`) | 판타지·SF의 공통 효과 후보 | 자연/폐허가 보이지만 효과가 주인공. 우주 장비가 필수인 설정에만 별도 버전 필요 |

마법의 이름을 과학 기술로 일괄 치환할 필요는 없다. 화면에는 작품의 실제 대상 이름이 남고 공용 그림은 예시다. 도감의 검색 보조 태그로 `에너지장`, `시간 현상` 등을 검토할 수 있지만, 원문의 설정 이름·의미와는 분리한다.

### 중요 아이템 80종: 물건 자체와 시대 표현을 구분

- 책·장신구·열쇠·지도·나침반·편지·모래시계·밧줄·삽은 공유 후보가 많다. 현재 책은 고풍스러운 장정, 편지는 밀랍 봉인, 열쇠는 고성 열쇠이므로 현대물에서도 그런 물건일 때 우선 사용한다.
- 부적·환약은 이미 동양 장면이다. 무협에 맞는 새 부적/환약을 다시 만드는 순서는 뒤로 둔다.
- 수갑·족쇄는 현재 무거운 쇠사슬 형태다. 현대 수사물의 수갑과 같은 그림이라고 단정하지 않는다.
- 호루라기는 현재 황동 도구와 중세 배경이다. 스포츠에서도 선택할 수 있지만 대표적인 현대 경기 도구를 이 그림 하나로 대신하지 않는다.
- 반지·목걸이·귀걸이는 로맨스와 일상에도 재사용할 수 있다. 웨딩 링이나 현대 액세서리처럼 디자인 차이가 중요한 경우만 버전을 추가한다.
- 휴대전화·노트북·현대 신분증·전자 기록 매체·경기 장비는 기존 80종에 없는 실질적인 공백이다.

### 세력·규칙·역사: 개념은 공유하지만 시각 보강 수요가 큼

계약, 혼례, 법률, 교육 조직, 금융 조직, 비밀결사, 동맹, 재건은 여러 장르에 존재한다. 다만 현재 이미지에는 중세 복식·깃발·석조 회관이 자주 등장한다. `아카데미→현대 학교`, `상단→현대 기업`, `정보 길드→경찰`을 자동 동의어로 붙이지 않는다. 조직의 개념과 기능도 다를 수 있다.

현대 조직의 일하는 모습과 현대 규정·법률의 상징을 추가하면 로맨스·추리·스포츠·일상·코미디가 함께 사용할 수 있다. 이 영역이 장르별 새 몬스터를 많이 만드는 것보다 우선이다.

### 종족·몬스터: 없는 설정을 채우지 않기

33종·60종은 판타지 외에도 호러·설화·초자연 로맨스·SF 혼합물에서 활용할 수 있다. 그러나 골렘을 로봇으로, 리자드맨을 외계인으로, 좀비를 일반 질병 환자로 자동 연결하지 않는다. SF용 종족은 설정상 지성을 가진 집단일 때, 기계 적은 몬스터 개체군의 의미에 맞을 때 별도 후보로 취급한다. 단순 로봇 장비는 아이템일 수 있다.

기본 그림은 대상의 외형을 모르는 상황에서 사용한다. 대표 장면처럼 특정 종족·조직·물건을 단정하지 않는다. 장르마다 7장을 모두 새로 만들기보다 다음 모티프를 공유하고 배경이 문제인 것만 변형한다.

| --- | --- | --- |

## 8. 신규 제작 후보: 우선 40개로 검토할 수 있는 안

아래는 **제작 확정 목록이 아니라 공백을 메우는 1차 후보**다. 장르별 출현 빈도·실제 사용량에 따른 순위는 아직 없고, 여러 장르가 함께 쓰는 정도와 현 자산 공백을 기준으로 배치했다. 분류 카드/기본 그림에 같은 자산을 사용할 수 있는지는 용도별로 따로 승인한다. 이 40개에 초기 화면 80장·기본 그림 70장을 자동으로 더하지 않는다.

일반적인 회사·교실을 만드는 것과 모든 회사·모든 교실의 개별 그림을 만드는 것은 다르다. 기존 숲처럼 대표 유형 하나를 여러 고유 대상이 공유한다. 스포츠도 축구공을 모든 종목의 공에 매칭하지 않으며, 지원할 종목을 늘릴 때 농구공·야구 장비 등을 추가한다.

추가 검토 후보: 현대 경찰서·아파트 복도·지하철·식당·공장·체육관, 현대 수갑·사진/녹음 매체·신분증과 구분되는 출입 카드, 농구·야구 장비·트로피, 무협 암기·의복·문규, 우주복·드론·기계형 위협·통신/추진 장치. 현재 40개가 승인되어도 이것들을 함께 생성하는 것으로 해석하지 않는다.

규칙·역사의 학교 규정·대회 운영은 지속적인 제도를 뜻한다. 단발 경기 결과·개별 사건·선수의 현재 상태는 현 추출 제외 기준에 걸릴 수 있다. 이미지가 추가되어도 해당 항목의 추출 정확도가 자동 개선되는 것은 아니다. 운동 기술·일반 추리 능력을 POWER_SYSTEM으로 넓히는 일은 별도 정책 검토라서 위 40개에서 제외했다.

## 9. 단계별 실행안

1. **기존 자산 정리:** 별도 기본 7장의 연결 차이를 해소하고, 현재 manifest의 안정적인 ID를 기준으로 공통·시대·분위기·추천 장르를 기록한다. 적용된 migration을 수정하지 않는다.
2. **화면용 조합안:** 장르별 초기 8칸과 기본 7칸에 어떤 기존 자산을 넣을지 정한다. 로맨스·코미디·일상·기타는 하나의 매핑을 공유하며 첫 구성표를 완성했다. 같은 파일을 여러 칸/장르가 참조한다.
3. **기존 그림만으로 추천 도감 구성:** 이름·별칭 검색과 전체 도감 접근을 유지하면서 장르에 맞는 결과를 먼저 보여준다. 작품 장르 변경은 추천/기본 표시만 갱신하고 수동 선택·개인 이미지를 보존한다.
4. **공백 제작:** 현대 공통부터 만들고, 무협·SF·스포츠 묶음은 목표 장르 우선순위에 따라 진행한다. 위 40개는 검토 가능한 상한 묶음이며 한 번에 생성할 필요는 없다.
5. **보강 후 검수:** 같은 그림을 무협·SF에서 사용했을 때 인물·장비가 충돌하지 않는지, 모바일 크롭과 작은 썸네일에서 알아볼 수 있는지, 결과 없음/전체 도감/개인 선택을 확인한다.

### 구현에 필요한 범위

- Front: 작품 장르 전달, 초기 카드/기본 그림 선택, 추천·전체 도감 전환과 검색, 이미지 실패 시 같은 테마의 기본값, 모바일 표시.
- Java/DB: 공용 이미지의 복수 추천 장르·테마 메타데이터, 테마별 기본 매핑, 장르를 고려한 추천 조회와 일관된 페이지 정렬. 현재 `is_default`의 분류당 하나 제약을 그대로 둔 채 장르별 기본을 추가할 수 없으므로 별도 매핑 등 schema 설계가 필요하다.
- 자산: 기존 ID·원본 유지, 새 버전 등록, WebP 최적화·S3 업로드·manifest/추가 migration. 같은 PNG를 장르별 S3 key로 반복 복제할 필요는 없다.
- AI: 이번 범위에서는 변경 없음. 추천 이미지를 고르는 동작과 원문에서 설정을 추출하는 동작을 분리한다.

완료 기준은 10개 장르에서 7개 enum을 유지하고, 추천이 비어도 전체 도감을 사용할 수 있으며, 기본·실패·새로고침 상태가 동일한 테마를 따르고, 사용자 선택이 장르 변경에도 유지되는 것이다.
