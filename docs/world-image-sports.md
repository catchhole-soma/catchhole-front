새 구성은 기본·전체 4장, 조직 4종, 장소 9종, 아이템 12종, 규칙·역사 3종이다. 선택 도감은 **신규 28종 + 기존 28종 = 56종**이다. 자연 7·현대 공통 13·추리 소품 4·공용 도구 4종을 재사용한다.

초기 8칸은 새 5종과 기존 3종, 기본 7칸은 새 3종과 기존 4종이다. 초기 장소는 종합 경기장, 종족은 현대 공통 기본이다. 장소·몬스터·능력 기본은 기존 안개 속 길·괴물 v4·추상 빛의 흐름을 공유한다.

## 제작 항목

- 세력: 스포츠 구단, 학교 운동부, 스포츠 협회, 코칭 스태프.
- 장소: 종합 경기장, 실내 체육관, 야구장, 수영장, 테니스장, 훈련실, 라커룸, 빙상장, e스포츠 경기장.
- 중요 아이템: 축구공, 농구공, 배구공, 야구 장비, 테니스 라켓, 배드민턴 라켓, 복싱 글러브, 러닝화, 경기용 자전거, 스포츠 메달, 트로피, 초시계.
- 규칙·역사: 대회·리그 규정, 선수 등록·자격 제도, 이적·선수 계약 제도.

## 판단과 후속 연결

- 팀·운동부·협회·코치진을 조직으로, 경기장·훈련실·라커룸을 장소로 구분했다. 얼굴·특정 구단·브랜드보다 협업과 시설을 강조했다.
- 구기·수영·빙상·훈련·e스포츠를 포함한다. 모든 종목을 완전히 덮는 목록은 아니며 종목이 다른 이미지도 같은 분류의 전체 도감에서 직접 고를 수 있다.
- 선수·학생은 종족이 아니고 라이벌은 몬스터가 아니다. 종족·몬스터·마법 분류의 의미와 공통 기본을 유지하고 해당 설정이 없으면 대상을 만들지 않는다.
- 야구 장비는 글러브·배트·공을 한 장면에 둔 공용 그림이다. 별칭 검색을 보조하되 세 물건이 같은 대상이라는 자동 매칭 규칙으로 사용하지 않는다.
- 메달·트로피는 대회와 성적을 특정하지 않는 현대 버전이다. 등록·이적·대회 규정은 제도이며 특정 선수의 성과나 일회성 계약 결과를 표현하지 않는다.

하나의 공용 ID·원본에 여러 테마를 연결하고 모든 재사용 후보를 같은 분류 선택 목록에 포함한다. 분위기 설명은 참고용이며 노출 조건이 아니다. 별칭은 검색 보조로만 기록하고 LLM 프롬프트·7개 enum·기존 자동 매칭 규칙·캐릭터 정책을 변경하지 않는다. 사용자 수동·개인 선택과 잠금 상태가 장르 변경보다 우선한다.

PNG 32개는 내장 image_gen으로 생성한 1536×1024 원본이다. 구단 그림의 브랜드 형태와 훈련실의 인물을 제거한 v2를 선택해 총 34회 생성/편집했다. 실제 프롬프트·편집 이력·별칭·SHA·경로를 기록했다. 갤러리 표시 검증 결과는 GALLERY_CHECK.json에 있다.

자료는 다중 저장소 로컬 작업공간에 있다. S3·manifest 등록, 장르별 초기/기본/목록 조회 연결과 별도 기본 PNG 등록 차이를 추가 migration으로 해소하는 작업은 아직 남아 있다. 서비스 코드 변경이 없어 앱 회귀 테스트는 실행하지 않았다.
