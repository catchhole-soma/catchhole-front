선택 도감은 **신규 14종 + 기존 66종 = 80종**이다. 기존 초자연 종족 6·조직 4·장소 10·몬스터 12·능력 8·소품 10·역사 6·현대/추리 10종을 함께 제공한다. 기존 이름과 공용 ID·원본을 유지한다.

초기 8칸은 새 5종과 기존 3종, 기본 7칸은 새 3종과 기존 4종이다. 초기 장소는 폐병원, 초기 능력은 기존 저주다. 기본은 안개 속 길·괴물 v4·추상 빛의 흐름과 추리의 기록 기본을 공유한다.

## 표현과 연결

어두운 환경에서도 대상이 읽히도록 안개와 작은 조명을 사용했다. 기본 그림은 정체를 확정하지 않고 괴물 그림은 형태를 식별할 수 있게 만들었다. 기존 마법 인형은 물건, 새 살아 움직이는 인형은 몬스터로 구분한다. 폐쇄 공동체를 사교 집단이나 악한 집단으로 자동 판단하지 않는다.

기존 재사용 후보 66종은 모두 같은 분류의 선택 목록에 포함한다. 배경·분위기 설명은 노출 조건이 아니다. 밝은 집·병원·자연도 호러 작품의 장소로 선택할 수 있다.

원본 18개는 내장 image_gen으로 생성한 1536×1024 PNG다. 실제 프롬프트·별칭·원본 경로·SHA를 색인에 저장했다. 초기 실행 상태가 끊겼을 때 이미 생성된 종족 기본 1장을 확인해 복구했고 나머지는 완료 응답을 기록했다.

자료는 다중 저장소 로컬 작업공간에 있다. S3·manifest 등록, 장르별 조회/표시, 별도 기본 이미지 연결 차이를 해소할 추가 migration은 후속 작업이다. 7개 enum·LLM 프롬프트·자동 매칭·캐릭터 정책은 변경하지 않았다. 수동·개인 선택과 잠금 상태를 보존한다. 앱 코드 변경이 없어 앱 회귀 테스트는 실행하지 않으며 갤러리 검증은 `GALLERY_CHECK.json`에 기록한다.
