위 자료는 다중 저장소 로컬 작업공간에 저장했다. 새 원본의 S3 업로드나 장르별 서비스 연결이 완료된 상태는 아니다.

## 구성

| 용도 | 새 그림 수 | 내용 |
| --- | ---: | --- |
| 기본·전체 | 5 | 종족·세력·규칙 역사·아이템 기본, SF 전체 전경 |
| 종족 | 2 | 지성 외계 종족, 지성 인공 종족 |
| 세력 | 4 | 함대 조직, 미래 연구 조직, 거대 기업, 개척지 연합 |
| 장소 | 8 | 우주 정거장, 함교, 미래 도시, 행성 개척지, 첨단 연구실, 우주항, 외계 유적, 궤도 거주구 |
| 몬스터 | 2 | 외계 포식 생물, 폭주 전투 기계 |
| 능력 | 2 | 에너지 방어장, 나노머신 제어 |
| 아이템 | 6 | 단말기, 에너지 총, 우주복, 정찰 드론, 동력 셀, 데이터 칩 |
| 규칙·역사 | 3 | 성간 조약, 인공 지성 권리, 행성 검역 규약 |

선택 도감은 **신규 27종 + 기존 43종 = 70종**이다. 기존 43종은 자연 지형 13, 능력 현상 10, 생물형 위협 8, 물건·재료 4, 현대 공통 8로 구성했다. 모두 같은 분류의 SF 이미지 변경 목록에 포함하며, 복식·배경 설명은 선택 참고용이다.

초기 8칸은 새 7종과 기존 몬스터 기본을 조합한다. 기본 7칸은 새 4종과 기존 안개 속 길·안개 속 괴물 v4·추상 빛의 흐름을 조합한다. 미래 도시·방어장은 초기/도감이 같은 원본을 공유한다.

## 의미와 후속 연결

- 지성 인공 종족·적대 기계형 몬스터·정찰 드론 장비를 구분한다. 함대/함교, 연구 조직/연구실도 별개다.
- 기존 마법 그림을 SF에서 공유해도 마법과 기술의 원인을 병합하지 않는다. 장르 목록 포함과 실제 대상 자동 매칭은 별도다.
- 7개 enum, 추출 프롬프트와 매칭 규칙을 변경하지 않는다. 별칭은 선택기 검색용이며 일반 기술 장비를 모두 능력으로 분류하지 않는다.
- 공용 이미지 ID와 원본에 여러 장르/테마를 연결하고 중복 ID는 한 번만 보여준다. 수동·개인 선택과 잠금 상태를 보존한다.
- 별도 기본 PNG를 새 manifest·추가 migration으로 등록한다. 현재 catalog의 기본 행과 초기 그림의 차이를 해소하되 적용된 migration은 수정하지 않는다.

선택한 32개 PNG는 1536×1024다. 내장 image_gen을 사용했으며 종족/기록 기본을 한 번씩 다시 생성해 총 호출은 34회다. 제외 시안 사유·원본 경로, 실제 프롬프트·별칭·SHA를 색인에 남겼다. 이미지 원본 검증과 갤러리 표시 검증을 수행하며 결과는 `GALLERY_CHECK.json`에 기록한다. 실제 앱 코드를 바꾸지 않아 앱 회귀 테스트는 실행하지 않았다.
