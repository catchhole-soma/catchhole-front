# 챗봇 근거 표시

답변의 근거 번호는 `[1]` 배지로 표시한다. 선택하면 근거 창에서 같은 번호를 스크롤하고 초점을 옮긴다. `근거 N개`는 전체 근거를 연다. 창을 닫으면 선택했던 버튼으로 초점을 돌려준다.

## 번호와 데이터

- 번호는 서버의 `sources` 순서 뒤에 `retrievalSources` 순서를 이어 붙인다. 성공한 조회 수로 다시 계산하지 않는다.
- 직접 근거 하나에 여러 항목/인용이 있더라도 하나의 번호 아래 표시한다. 실패한 직접 근거는 같은 번호에 확인 불가 상태를 남긴다.
- 직접 근거 조회 앞뒤의 질문 조회와 attempt 검증, 취소 요청, 인증·작품·세션 경계는 기존 동작을 유지한다. 마지막 검증이 실패하면 인용을 노출하지 않는다.
- 모달은 회차와 인용문을 우선 표시하고 원문/설정 이동은 별도 링크로 제공한다. 긴 원문은 본문 영역에서 스크롤하며 상단 닫기·근거 선택은 유지한다.
- 직접 근거의 `value`는 `조회한 설정값`으로 표시하며 원문 인용과 구분한다. 직접 입력·과거 이력처럼 원문을 읽을 수 없는 경우에도 반환된 값은 표시한다. `valueTruncated`이면 일부 내용이 생략되었음을 안내하고, 값의 줄바꿈·HTML처럼 보이는 문자열·0은 그대로 보존한다.

## 현재 텍스트 계약의 경계

서버는 별도 인용 위치 필드 없이 자연어에 근거 번호를 덧붙인다. `ChatAnswerText`는 서버 렌더러의 행 끝 `근거 1, 3`, `· 근거 1`, `(근거 2)`와 문장부호 뒤의 중간 `(근거 1)` 형식만 표시용으로 해석한다. 번호 중 하나라도 실제 근거 범위 밖이면 표시를 바꾸지 않는다. 일반 숫자·본문 중의 근거 언급·따옴표와 인라인 코드 내부는 보존하며, HTML로 해석하지 않는다. 모달 인용문에는 이 변환을 적용하지 않는다.

구분 기호 없이 행 끝에 놓인 설정값이 근거 표기와 완전히 같으면 텍스트만으로 의미를 판별할 수 없다. 더 넓은 문장 패턴을 추측해 지우지 않으며, 향후 문장별 인용 위치가 필요하면 서버의 구조화된 인용 계약으로 확장한다. 같은 문장에서 서로 다른 근거를 인용할 때 번호를 합쳐 문장 전체의 근거로 만들지 않는다.
