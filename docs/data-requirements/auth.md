### 보호 라우트 세션 확인

- access token이 있는 상태로 보호 화면에 진입하면 `GET /api/v1/auth/me`로 현재 세션을 확인한다.
- 401은 인증 만료로 처리해 토큰을 제거하고 로그인 화면으로 이동한다.
- 5xx나 네트워크 오류는 일시적 장애로 처리해 토큰을 유지하고, 보호 화면의 데이터를 노출하지 않은 채 오류 안내와 재시도를 제공한다.

## 랜딩 (SLanding)

**URL**: [`/landing`](https://www.catchhole.com/landing)

![랜딩 화면](../screens/k7pzFp.png)

비로그인 사용자에게 CatchHole의 핵심 가치를 소개하고 로그인·회원가입으로 유도하는 진입 화면.

**1. 화면에 표시할 데이터**
- 상단 헤더: CatchHole 로고, 로그인·회원가입 버튼
- Hero: 서비스 업데이트 배지, 핵심 소개 문구와 설명, 무료 시작·로그인 버튼, 신뢰 요소, 서비스 분석 화면 예시
- 주요 기능 카드: AI 대조 분석, 일관성 검사, 오류 리포트
- 하단 가입 유도 영역
- Footer: 개인정보 처리방침, 이용약관, 문의 문구


**2. 사용자 액션**
- 로그인 버튼 → 랜딩 위에 [로그인](#로그인-slogin) 라우트 모달 열기
- 회원가입·무료 시작 버튼 → 랜딩 위에 [회원가입](#회원가입-ssignup) 라우트 모달 열기
- 서비스 안내 더보기 → 주요 기능 영역으로 스크롤
- 개인정보 처리방침 → [약관·개인정보 모달](#약관개인정보-모달-termsmodal)의 개인정보 탭 열기
- 이용약관 → [약관·개인정보 모달](#약관개인정보-모달-termsmodal)의 이용약관 탭 열기

**3. 화면 전환 식별자**
- 로그인 모달: `/login`
- 회원가입 모달: `/signup`
- 약관·개인정보 모달: `?terms=terms|privacy`


**4. 데이터 없음 / 실패 표시**
- FE 정적 화면이므로 별도의 로딩·빈 상태·실패 상태 없음

**5. 화면 데이터 요구사항**

**5-1. BE → FE 제공 데이터 요구사항**

현재 BE → FE 제공 데이터 없음. 화면 전체와 현재 노출 문구는 FE 정적 콘텐츠이며, 동적 통계 영역을 추가할 때 표시할 데이터의 의미를 다시 정의한다.

**5-2. FE → BE 전달 데이터 요구사항**
- 없음

**6. BE와 협의할 범위·상태값**
- Footer의 문의 항목은 현재 정적 문구만 표시 — 추후 문의 채널과 연결 방식 기획

## 로그인 (SLogin)


**URL**: [`/login`](https://www.catchhole.com/login)

![로그인 화면](../screens/tNdOk.png)

가입한 사용자가 이메일과 비밀번호로 인증하고 작품 목록에 진입하는 라우트 모달. 데스크톱에서는 랜딩 위 중앙 모달로 표시하고, 모바일에서는 전체 화면으로 표시한다.

> **MVP 범위 메모**: 로그인은 이메일·비밀번호만 지원한다. 소셜 로그인(카카오/Google) 버튼은 와이어프레임에 유지하되 MVP에서는 비활성 상태로 표시하고, 실제 연동은 MVP 이후 재논의한다. 회원 role(`USER`/`ADMIN`)은 FE 미사용(관리자 페이지 개발 시 재논의).

> **입력 정책**: 이메일은 필수이며 이메일 형식이어야 한다. 비밀번호는 필수이며, 길이·문자 조합 같은 비밀번호 생성 규칙은 [회원가입](#회원가입-ssignup)에서 검증하고 로그인에서는 빈 값 여부만 사전 검증한다.


**1. 화면에 표시할 데이터**
- 좌측 브랜딩 영역: CatchHole 로고, 서비스 소개, 이용약관·개인정보 처리방침
- 이메일·비밀번호 입력, 비밀번호 표시·숨김 버튼
- 로그인 버튼
- 카카오·Google 로그인 버튼(MVP 비활성)
- 회원가입 이동 링크


**2. 사용자 액션**
- 이메일·비밀번호 입력
- 비밀번호 표시·숨김
- 로그인 제출 → [작품 목록](./work.md#작품-목록-s0workpicker)
- 닫기·배경 선택·`Esc`·브라우저 뒤로가기 → 랜딩 복귀
- [회원가입](#회원가입-ssignup) 모달로 전환
- [약관·개인정보 모달](#약관개인정보-모달-termsmodal) 열기

**3. 화면 전환 식별자**
- 로그인 라우트 모달: `/login`
- 랜딩에서 연 경우 닫기 → 브라우저 뒤로가기, 직접 진입·인증 리다이렉트에서 닫기 → `/landing` 대체 이동
- 회원가입 전환: `/signup`으로 현재 히스토리 항목 대체
- 로그인 성공 시 데모 모드·데모 작품 데이터를 제거하고 `accessToken` 저장(이후 화면 접근 권한)
- 로그인 성공 → `/works`로 현재 히스토리 항목 대체
- 로그아웃 → `/landing`으로 현재 히스토리 항목 대체
- 약관·개인정보 모달: `?terms=terms|privacy`


**4. 데이터 없음 / 실패 표시**
- 이메일 미입력·이메일 형식 오류·비밀번호 미입력 ([입력 검증 오류](../screens/m3vaC0.png))
- 이메일 또는 비밀번호 불일치 ([인증 실패](../screens/w5lmQO.png))
- 네트워크 오류 ([네트워크 오류](../screens/l4QKr.png))
- 로그인 제출 중 로딩·중복 제출 방지 ([제출 중](../screens/bRQzK.png))
- 카카오·Google 로그인 버튼 비활성 상태

**5. 화면 데이터 요구사항**

**5-1. BE → FE 제공 데이터 요구사항**

**로그인 성공 후 인증 상태**

| 데이터 의미 | 형태·필수성 | 값 없음·조건 |
| --- | --- | --- |
| API 인증에 사용할 access token | 단일 값·로그인 성공 시 필수 | 로그인 실패 시 제공하지 않음 |
| 인증 갱신에 사용할 refresh token | HttpOnly 쿠키·로그인 성공 시 필수 | 로그인 실패 시 제공하지 않으며 FE가 본문 값으로 직접 읽지 않음 |

**로그인 실패**

| 데이터 의미 | 형태·필수성 | 값 없음·조건 |
| --- | --- | --- |
| 인증 실패 식별값 | 단일 상태값·자격 증명 불일치 시 필수 | `AUTH_INVALID_CREDENTIALS`; 이메일 미존재와 비밀번호 불일치를 구분하지 않음 |

**5-2. FE → BE 전달 데이터 요구사항**
- 이메일
- 비밀번호

**6. BE와 협의할 범위·상태값**
- 없음

## 회원가입 (SSignup)

**URL**: [`/signup`](https://www.catchhole.com/signup)

![회원가입 화면](../screens/VI8zP.png)

신규 사용자가 계정을 생성하고 자동 로그인 후 작품 목록에 진입하는 라우트 모달. 데스크톱에서는 랜딩 위 중앙 모달로 표시하고, 모바일에서는 긴 입력 폼을 스크롤할 수 있는 전체 화면으로 표시한다.

> **MVP 범위 메모**: 이메일·비밀번호 회원가입만 지원한다. 카카오·Google 회원가입 버튼은 와이어프레임에 유지하되 비활성 상태로 표시한다. 휴대폰 SMS 인증과 마케팅 수신 동의는 제외한다.

> **입력 정책**
> - 이름(필명): 필수, 최대 20자, 중복 허용. 화면에는 `이름 (필명)`, 문서와 전달 데이터에는 필명(`displayName`)으로 표기
> - 이메일: 필수, 이메일 형식, 중복 불가
> - 휴대폰 번호: 필수, 하이픈 없이 `010`으로 시작하는 11자리 숫자, 중복 불가
> - 비밀번호: 8자 이상 64자 이하, 영문·숫자 각 1개 이상, 특수문자 선택
> - 비밀번호 확인: 비밀번호와 일치
> - 이용약관·개인정보 처리방침: 하나의 체크박스로 묶어 필수 동의

**1. 화면에 표시할 데이터**
- 좌측 브랜딩 영역: CatchHole 로고, 서비스 소개
- 이름(필명)·이메일·휴대폰 번호·비밀번호·비밀번호 확인 입력
- 비밀번호·비밀번호 확인 표시·숨김 버튼
- 이용약관·개인정보 처리방침 통합 필수 동의 체크와 각 본문 링크
- 회원가입 버튼
- 카카오·Google 회원가입 버튼(MVP 비활성)
- 로그인 이동 링크


**2. 사용자 액션**
- 가입 정보 입력
- 비밀번호·비밀번호 확인 표시/숨김
- 이용약관·개인정보 처리방침 본문 확인
- 통합 필수 동의 체크
- 가입 제출 → 자동 로그인 → [작품 목록](./work.md#작품-목록-s0workpicker)
- 닫기·배경 선택·`Esc`·브라우저 뒤로가기 → 랜딩 복귀
- [로그인](#로그인-slogin) 모달로 전환


**3. 화면 전환 식별자**
- 회원가입 라우트 모달: `/signup`
- 랜딩에서 연 경우 닫기 → 브라우저 뒤로가기, 직접 진입에서 닫기 → `/landing` 대체 이동
- 로그인 전환: `/login`으로 현재 히스토리 항목 대체
- 가입·자동 로그인 성공 시 데모 모드·데모 작품 데이터를 제거하고 `accessToken` 저장
- 가입·자동 로그인 성공 → `/works`로 현재 히스토리 항목 대체
- 약관·개인정보 모달: `?terms=terms|privacy`

**4. 데이터 없음 / 실패 표시**
- 필명 미입력·길이 초과
- 이메일 미입력·형식 오류·중복 ([입력·중복 오류](../screens/ThXIG.png))
- 휴대폰 번호 미입력·형식 오류·중복 ([입력·중복 오류](../screens/ThXIG.png))
- 비밀번호 미입력·정책 불충족
- 비밀번호 확인 미입력·불일치
- 필수 약관 미동의 시 회원가입 버튼 비활성
- 네트워크 오류와 입력값 유지 ([네트워크 오류](../screens/f7oz8.png))
- 제출·자동 로그인 중 로딩과 중복 제출 방지 ([제출 중](../screens/tfhIa.png))
- 카카오·Google 회원가입 버튼 비활성


**5. 화면 데이터 요구사항**

**5-1. BE → FE 제공 데이터 요구사항**

**가입·자동 로그인 성공 후 인증 상태**

| 데이터 의미 | 형태·필수성 | 값 없음·조건 |
| --- | --- | --- |
| API 인증에 사용할 access token | 단일 값·가입과 자동 로그인 성공 시 필수 | 가입 또는 자동 로그인 실패 시 제공하지 않음 |
| 인증 갱신에 사용할 refresh token | HttpOnly 쿠키·가입과 자동 로그인 성공 시 필수 | 가입 또는 자동 로그인 실패 시 제공하지 않으며 FE가 본문 값으로 직접 읽지 않음 |

**가입 정보 중복 실패**

| 데이터 의미 | 형태·필수성 | 값 없음·조건 |
| --- | --- | --- |
| 이메일 중복 식별값 | 단일 상태값·이메일 중복 시 필수 | `AUTH_EMAIL_DUPLICATED` |
| 휴대폰 번호 중복 식별값 | 단일 상태값·휴대폰 번호 중복 시 필수 | `AUTH_PHONE_NUMBER_DUPLICATED` |

**5-2. FE → BE 전달 데이터 요구사항**
- 필명(`displayName`)
- 이메일
- 휴대폰 번호
- 비밀번호

비밀번호 확인과 약관 동의 여부는 FE에서만 검증하고 MVP에서는 BE에 전달하지 않는다.

**6. BE와 협의할 범위·상태값**
- 없음

## 약관·개인정보 모달 (TermsModal)

**URL 상태**: 호출 화면(`/landing`, `/login`, `/signup`) + `?terms=terms|privacy`

![이용약관 탭](../screens/BQqMv.png)

![개인정보 처리방침 탭](../screens/vZNPo.png)

비로그인 사용자가 서비스 이용약관과 개인정보 처리방침을 확인하는 공통 모달. Auth 라우트 모달에서 열면 그 위에 한 단계 더 쌓인다.

> **MVP 범위 메모**: 본문은 FE 정적 콘텐츠로 제공한다. 현재 Pencil과 FE에 작성된 본문은 화면 확인용 예시이며, 배포 전 별도로 작성·검토한 최종 이용약관과 개인정보 처리방침으로 교체한다. 약관 버전 관리와 사용자별 동의 이력 저장은 MVP 범위에서 제외한다.

**1. 화면에 표시할 데이터**
- 모달 제목: `법적 고지`
- 이용약관·개인정보 처리방침 탭
- 현재 선택된 탭의 활성 상태
- 선택한 탭의 약관 본문
- 닫기 버튼과 확인 버튼


**2. 사용자 액션**
- 이용약관·개인정보 처리방침 탭 전환
- 긴 약관 본문 스크롤
- 닫기 버튼 또는 확인 버튼 선택 → 모달을 닫고 기존 화면으로 복귀
- 모달 바깥 영역 선택 → 모달을 닫고 기존 화면으로 복귀
- `Esc`·브라우저 뒤로가기 → 약관 모달만 닫고 기존 랜딩 또는 Auth 모달 유지
