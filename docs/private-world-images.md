# 코드 없는 내 이미지 — GH199

캐릭터와 세계관의 `내 이미지`에서 바로 파일을 올리고 대표 이미지로 선택한다. 보관함 생성·보관용 코드 저장·잠금 해제를 요구하지 않는다. 로그인한 작품 소유자만 업로드·열람·선택·삭제할 수 있고, 새로고침 후에도 인증 API로 바로 표시한다. 공개 도감에 등록하지 않는다.

- PNG/JPG/WebP를 브라우저에서 PNG로 변환하며 썸네일을 만든다. 파일 8MB, 3,200만 화소/한 변 16,384px, 작품당 50개 제한을 유지한다. 서버에서도 실제 PNG와 해상도·크기를 검증한다.
- 기존 암호화 이미지는 데이터와 선택 관계를 보존한다. 카드에 `이미지를 다시 올려 주세요`를 표시하고 원본 재업로드·교체를 안내한다. 키 없는 자동 변환은 하지 않는다.
- 새 파일과 이름은 서버가 처리할 수 있으므로 서버도 열 수 없는 암호화라고 설명하지 않는다. 사용자 안내: `이 작품에서만 사용하는 이미지입니다. 로그인하면 별도 코드 없이 볼 수 있어요.`
- 작품의 인증된 파일 API를 사용한다. Query는 계정 세대별로 분리하고 GC 시간을 0으로 두며, 계정 변경/로그아웃에는 이전 세션의 늦은 업로드 응답과 Blob 표시를 폐기한다. Blob URL은 교체/언마운트에 해제한다.
- 현재 사용 중인 이미지 삭제는 거절한다. 다른 대표 이미지로 바꾼 뒤 삭제한다.

## 계약과 파일

- `private-image-upload.ts`: 이미지 검사, PNG 변환, 썸네일 준비.
- `private-image-session.ts`: 로그아웃/계정 전환 시 세션 변경 알림과 비동기 완료 차단.
- `PrivateWorldImagePicker`: 업로드·목록·선택·삭제. `PrivateSubjectImage`: 인증 파일 표시 및 이전 암호화 이미지 교체 안내.
- multipart `metadata`는 `{id, name}`이며 JSON part이다. 이미지 part는 PNG다. Backend OpenAPI에서 SDK를 생성한다. 생성 파일은 직접 편집하지 않는다.
- Java V67을 먼저 반영해야 새 업로드가 동작한다. 서버는 이전 CHI1 요청도 계속 수용한다.

## 검증

`e2e/private-images.spec.ts`는 PNG/JPEG 변환·잘못된 파일 거절·계정 변경 후 이전 목록 제거·암호화 이미지 안내를 확인한다. `private-images-live.spec.ts`와 `character-images-live.spec.ts`는 일회용 로컬 계정으로 업로드/선택/새로고침/작품 안 공유/미인증 파일 접근/사용 중 삭제 거절/삭제를 확인한다. 테스트 종료 시 생성 작품과 계정을 정리한다. 실행 방법은 [로컬 fixture 안내](local-image-live-tests.md)를 따른다. 현재 화면은 `docs/screens/gh199/`에 저장했다.
