# 로맨스·코미디·일상·기타 공통 이미지 제작 결과

2026-09-16 · GH194 · **이미지 제작 완료 / 장르별 서비스 연결 전**

2026-09-16 추가 결정: **기타도 일상과 같은 초기 8칸·기본 7칸·추천 도감 구성을 사용**한다. 추가 이미지 생성이나 원본 복제 없이 동일한 `modern-common` 테마를 참조한다.

네 장르는 `modern-common` 테마 하나를 공유한다. 따뜻한 자연광·나무 재질·차분한 녹색을 중심으로 현대 생활 공간을 구성했다. 기존 7개 enum과 원문 추출·비교 프롬프트는 유지한다.

## 제작한 18장

| 용도 | 수량 | 내용 |
| --- | ---: | --- |
| 공통 기본 | 4 | 종족: 일상복 인물의 뒷모습 / 세력: 비어 있는 원형 회의 공간 / 규칙·역사: 기록 보관 공간 / 아이템: 닫힌 보관함 |
| 전체 분류 전경 | 1 | 거리·공원·주거·카페가 함께 보이는 현대 동네 |
| 세력 도감 | 3 | 회사 조직, 학교 조직, 의료 조직 |
| 장소 도감 | 5 | 현대 도심, 교실, 주거 실내, 카페, 병원 실내 |
| 아이템 도감 | 3 | 휴대전화, 노트북, 현대 신분증 |
| 규칙·역사 도감 | 2 | 현대 계약 제도, 학교 규정 |

각 PNG는 1536×1024의 3:2 이미지다. 내장 `image_gen`으로 개별 생성했고 18개 원본과 실제 프롬프트, 검색 별칭, SHA-256을 프로젝트 안에 저장했다. 원본은 보존하고 갤러리용 WebP만 별도로 변환했다.

## 초기 화면 8칸과 기본 7칸

| 분류 | 초기 화면 | 미선택 기본 |
| --- | --- | --- |
| 종족 | 새 인물 뒷모습 | 같은 그림 |
| 세력 | 새 원형 회의 공간 | 같은 그림 |
| 장소 | 새 현대 도심 | 기존 안개 속 길 |
| 몬스터 | 기존 안개 속 괴물 v4 | 같은 그림 |
| 마법·능력 | 기존 추상 빛의 흐름 | 같은 그림 |
| 규칙·역사 | 새 기록 보관 공간 | 같은 그림 |
| 중요 아이템 | 새 닫힌 보관함 | 같은 그림 |
| 전체 | 새 현대 동네 전경 | 해당 없음 |

초기 8칸은 새 6종+기존 2종, 기본 7칸은 새 4종+기존 3종이다. 전체에 같은 그림이 반복 참조되므로 8장+7장을 따로 생성하지 않았다. 캐릭터 공통 그림과 기존 인간 군상은 이번 테마 제작과 별개로 유지한다.

**후속 연결 시 확인:** 재사용하는 기본 3장은 `world-defaults/2026-09-15-v1/`의 별도 PNG다. 현재 manifest의 default 행은 초기 분류 그림을 참조하므로 기존 ID만 재사용하면 다른 그림이 나올 수 있다. `THEME_PLAN.json`의 원본 경로를 기준으로 추가 등록한다. 적용된 migration은 수정하지 않는다.

## 추천 도감 구성

신규 13종과 다음 기존 22종을 합친 **35종**을 추천 묶음으로 계획했다. 각 화면에서는 현재 분류에 해당하는 항목만 보여준다.

- 자연 지형 13종: 숲, 산·산맥, 평원·초원, 사막, 설원, 늪, 동굴, 협곡, 화산, 강, 호수, 바다, 섬.
- 기존 소품 9종: 일반 서적, 목걸이, 귀걸이, 팔찌, 브로치, 보석, 밧줄, 삽, 깃털.

고풍스러운 책 장정이나 장신구 디자인은 그대로 보존한다. 인간, 열쇠, 편지, 나침반, 모래시계, 호루라기, 가면, 계약서, 혼인·축제·장례·법률 제도, 시간·중력·염동력은 **15종의 조건부 후보**로 분리했다. 장르만 보고 초능력 설정을 추측하거나 고전 그림을 현대 디자인으로 재표기하지 않는다.

네 장르가 항상 현대 배경인 것은 아니므로 같은 분류의 전체 도감도 계속 선택할 수 있게 한다. 검색 별칭은 선택기 탐색용이며 자동 매칭 규칙으로 넣지 않았다. `학교 조직`과 `교실`, `의료 조직`과 `병원 실내`, `계약 제도`와 물건인 `계약서`의 의미를 구분한다.

## 확인 결과와 남은 작업

- 18개 PNG 원본의 디코딩·해상도·SHA, 프롬프트·별칭 존재, 8/7칸 누락, 기존 도감 ID·분류·원본 경로를 검증했다.
- 새 이미지 18장과 구성 미리보기를 시각 점검했다. 갤러리의 65개 이미지 배치가 모두 로드되었으며 1440px·390px에서 확인했다. 모바일 가로 넘침과 페이지 오류는 없었다. 사용자 최종 시각 승인은 별도다.
- 이번에는 앱 코드·DB·S3·LLM을 변경하지 않아 앱 회귀 테스트를 실행하지 않았다. 제작 갤러리 확인은 실제 서비스 연동 검증을 대신하지 않는다.
- 다음 구현: 테마별 초기/기본 매핑, 복수 추천 테마 메타데이터, 자산 업로드와 추가 migration, 장르별 추천·전체 도감 조회/표시.
- 사용자 직접 선택·개인 업로드는 장르가 바뀌어도 보존한다. 잠긴 개인 이미지는 기본 그림으로 바꾸지 않고 잠금 상태를 유지한다.
- 수사 조직·현대 법정·감시 카메라는 추리 묶음에서 검토한다. 다음 제작 묶음으로는 기존 자연·내공·부적·환약을 공유할 수 있는 무협이 적합하다.

기존 [전체 장르 기획](world-image-genre-plan.md)의 40개 후보와 이 제작 결과의 18장은 서로 다른 집계다. 이번 18장은 그중 현대 생활 도감 13종에 기본/전체 5장을 더한 수량이다.
