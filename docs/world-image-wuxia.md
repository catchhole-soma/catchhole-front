모든 원본은 1536×1024의 3:2 PNG이며 내장 `image_gen`으로 개별 생성했다. 32개 원본과 실제 프롬프트, 검색 별칭, SHA-256을 저장했다. 갤러리용 WebP는 원본을 보존하고 리사이즈·포맷 변환만 했다.

## 초기 화면 8칸과 기본 7칸

| 분류 | 초기 화면 | 미선택 기본 |
| --- | --- | --- |
| 종족 | 새 강호 여행자 뒷모습 | 같은 그림 |
| 세력 | 새 회합 공간 | 같은 그림 |
| 장소 | 새 강호 거리 | 기존 안개 속 길 |
| 몬스터 | 기존 안개 속 괴물 v4 | 같은 그림 |
| 마법·능력 | 기존 기·내공 | 기존 추상 빛의 흐름 |
| 규칙·역사 | 새 기록 보관 공간 | 같은 그림 |
| 중요 아이템 | 새 닫힌 목함 | 같은 그림 |
| 전체 | 새 강호 전경 | 해당 없음 |

초기 화면은 새 6종+기존 2종, 기본은 새 4종+기존 3종이다. 초기 능력 대표와 미선택 능력 기본의 용도를 구분한다. 캐릭터의 인간 군상이나 공통 기본 그림은 이번 작업에서 변경하지 않았다.

재사용하는 기본 3장은 `world-defaults/2026-09-15-v1/`의 별도 원본이다. 현 catalog의 기본 행이 초기 분류 그림을 참조하는 차이는 이후 새 manifest·추가 migration에서 해소한다. 기존 migration을 수정하지 않는다.

## 기존 이미지와의 조합

신규 도감 27종 + 기존 추천 23종 + 추가 기존 20종으로 **무협 선택 도감 70종**을 계획했다. 각 선택 화면은 같은 분류에 속한 항목만 보여준다.

- 자연 13종: 숲, 산·산맥, 평원·초원, 사막, 설원, 늪, 동굴, 협곡, 화산, 강, 호수, 바다, 섬.
- 능력 1종: 기·내공.
- 아이템 9종: 부적, 환약, 밧줄, 갈고리, 곡괭이, 삽, 보석, 깃털, 금속 주괴.

기존 인간·구미호·도깨비, 요수/유령 9종, 단검·곡도·활·독약, 독·신체 강화·마기·은신 등 총 20종도 무협 이미지 변경 목록에 포함한다. 복식·배경 설명은 선택 참고용이며 노출 조건이 아니다. 전체 도감도 계속 직접 선택할 수 있게 한다.

하나의 공용 이미지 ID에 여러 장르/테마를 연결한다. 파일과 도감 항목을 복제하지 않고 작품 테마와 현재 분류로 선택 목록을 조회하며, 여러 테마가 겹치면 ID로 중복 제거한다. 테마 포함은 이미지 선택 허용 범위이며 자동 매칭 여부와는 별개다. 사용자 수동 선택은 장르가 바뀌어도 유지한다. 이 연결 방식은 후속 구현 대상이다.

## 유지할 의미와 후속 작업

- 마교는 가상 무림 조직이며 마족 종족을 의미하지 않는다. 문파/산문, 세가/장원, 비무대/대회 제도의 조직·장소·규칙 차이를 유지한다.
- 별칭은 선택기 검색 보조다. 고유 문파명을 일괄 등록하거나 검기·검강의 세부 설정을 같은 의미로 자동 병합하지 않는다.
- 경공·검기·장력은 인물보다 능력의 궤적과 형태를 크게 표현했다. 점혈은 수련용 모형으로 국소적인 기의 정지를 상징한다.
- 32개 원본 해상도·SHA·프롬프트·별칭과 8/7칸 매핑을 검사했다. 갤러리의 85개 이미지 배치와 209개 파일 링크를 확인했고 1440px·390px·320px에서 페이지 오류·모바일 가로 넘침이 없었다. 사용자 최종 시각 승인은 별도다.
- 실제 앱·DB·S3·LLM 변경은 없으며 앱 회귀 테스트는 실행하지 않았다. 후속 구현에서 자산 업로드, 테마 메타데이터, 장르별 추천·전체 도감 표시, 수동/개인 이미지 및 잠금 상태 보존을 연결한다.

후속 제작 후보는 산적채·수적 조직·관아·의관·대나무 숲·은거 동굴·독공·중원 도/봉·침구·약초·독약 변형이다. 이번 제작 완료 목록에 포함하지 않았으며 실제 설정 수요를 보고 추가한다.
