# 랜딩·공개 체험 화면 명세 — GH244

최종 승인 기준: 2026-10-12. 이슈: [catchhole-backend-java#244](https://github.com/catchhole-soma/catchhole-backend-java/issues/244).

## 랜딩 `/landing`

기존 영상 Hero 아래에서 제품 소개 → 원고 보호 안내 → 핵심 기능 → 주요 서비스·예정 기능 → 제작자 이야기 → 체험 CTA·푸터 순서로 읽는다.

| 제품 소개 | 화면과 역할 |
| --- | --- |
| 원고에서 발견 | 가상 원고와 추출된 캐릭터 직업을 연결 |
| 원문과 함께 확인 | 실제 검토 화면의 기존값·제안값·반영 방식·근거 |
| 나만의 설정집 | 실제 캐릭터·세계관 상세 화면 |
| 변화의 기록 | 현재 타임라인의 회차별 직업과 원문 근거 |

- 네 장면은 현재 제품 컴포넌트에 가상 데이터를 주입해 캡처한 소개 이미지다. 예전 8단계 탭·자동 순환·아코디언은 사용하지 않는다. 직접 조작은 마지막 링크의 `/demo`에서 제공한다.
- 900px 이하에서는 설명 다음 화면을 쌓고, 520px 이하 검토는 별도 모바일 캡처를 사용한다.
- 제품 소개부터 하단까지 최초 노출 시 한 번 페이드 업한다. 이동 72px·900ms, 흐림 2px·350ms, 순차 지연 180ms. 모션 감소·키보드 포커스에서는 즉시 표시한다.
- 업로드·AI 분석 카드에 생성 일러스트를 사용한다. 예정 기능은 별도 제목과 `업데이트 예정`으로 구분한다.
- 제작자 이야기는 웹소설 독자가 작가의 설정 관리 수고를 줄이려고 시작한 계기를 담는다.
- 실제 업로드의 자동 반영 기본값과 단일 회차 직접 검토 예시를 구분한다. 원고 학습 미사용 안내·개인정보 링크와 로그인/가입 라우트 모달을 유지한다.

## 공개 체험 `/demo`

원고 확인 → 분석 시뮬레이션 → 캐릭터 확정 → 세계관 수정·확정 → 근거 부족 후보 제외 → 결과 탐색 → 사용자가 `체험 마치기` → 완료 화면.

- 결과 탐색에는 실제 `CharacterDatabase`, `CharacterTimelineModal`, `WorldSettingDatabase`를 재사용한다. 백엔드·LLM 호출 없이 fixture와 메모리만 사용한다.
- 결과 탐색에서는 특정 근거를 열지 않아도 `체험 마치기`를 누를 수 있다. 상세창이 열려 있어도 완료로 이동하며 상세 선택 URL을 정리한다.
- 거꾸로숲 외 상세를 열면 현재 상세의 닫기를 안내한다. 닫힌 목록에서는 거꾸로숲 카드, 해당 상세에서는 귀환문의 조건 근거를 안내한다. 가려진 목록을 강조하지 않는다.
- 안내된 세계관 근거를 확인하면 `체험을 모두 마쳤어요`와 자유 탐색 안내를 유지한다. 근거·상세를 닫거나 다른 대상·탭을 열어도 안내를 되돌리지 않는다. 이후 안내 강조는 종료하며 자동으로 완료 화면에 넘기지 않는다.
- 완료 화면은 GPT 생성 종이책 세계관 이미지, 실제 제목·설명, `내 작품으로 시작하기`·`다시 체험하기`, 가상 원고 고지만 표시한다. 하단 결과 기록과 중복 요약은 없다.
- 데스크톱은 그림 왼쪽 여백에 텍스트·CTA, 900px 이하에서는 텍스트 다음 그림을 배치한다. 이미지는 장식으로 처리하고 버튼·제목은 HTML로 유지한다.
- 시작하기는 `/signup`으로 replace 이동하며 가입창 닫기는 `/landing`으로 돌아간다. 재체험·새로고침은 초기 원고부터 시작한다. API·localStorage·sessionStorage에 체험 데이터를 저장하지 않는다.
