자료는 다중 저장소 로컬 작업공간에 저장했다. 새 원본의 S3 업로드나 장르별 서비스 연결은 후속 작업이다.

## 구성

| 용도 | 새 그림 수 | 내용 |
| --- | ---: | --- |
| 기본·전체 | 4 | 세력·규칙 역사·아이템 기본, 추리 전체 전경 |
| 세력 | 4 | 수사 조직, 탐정 사무소 조직, 감식 조직, 범죄 조직 |
| 장소 | 7 | 탐정 사무실, 조사실, 감식실, 기록 보관실, 비 오는 골목, 외딴 저택, 열차 객실 |
| 아이템 | 7 | 감시 카메라, 녹음기, 저장 장치, 현대 열쇠, 사진, 증거 보관 봉투, 회중시계 |
| 규칙·역사 | 3 | 사법 절차, 증거 보존 규정, 상속 제도 |

선택 도감은 **신규 21종 + 기존 40종 = 61종**이다. 기존 40종은 자연 지형 10, 현대 공통 13, 물건·고전 단서 8, 고전 장소 3, 초자연·초능력 소재 6으로 구성했다. 모두 같은 분류의 추리 이미지 변경 목록에 포함하고, 배경·분위기 설명은 선택 참고용으로 둔다.

초기 8칸은 새 5종과 기존 3종, 기본 7칸은 새 3종과 기존 4종이다. 종족은 현대 공통 기본, 장소 기본은 안개 속 길, 몬스터는 최신 안개 속 괴물 v4, 능력은 추상 빛의 흐름을 공유한다. 비 오는 골목은 초기 장소와 도감에서 같은 원본을 사용한다.

## 표현과 후속 연결

- 수사·탐정·감식 조직과 사무실·조사실·감식실을 분리한다. 탐정의 추론을 초능력, 범인을 몬스터, 직업을 종족으로 바꾸지 않는다.
- 현대 소품과 고전 저택·열차·회중시계를 함께 제공한다. 추리 장르만으로 작품 시대나 사건 관련성을 확정하지 않는다.
- 사진은 건물 사진, 봉투는 내용물이 보이지 않는 구도다. 법·규칙 그림은 소설 도감용 상징이며 특정 국가의 실제 절차를 재현하지 않는다.
- 공용 이미지 ID와 원본 하나에 여러 장르/테마를 연결한다. 테마 목록 포함과 실제 대상 자동 매칭은 별개이며 별칭은 선택기 검색용이다.
- 7개 enum과 LLM 프롬프트, 기존 자동 매칭 규칙을 변경하지 않는다. 수동·개인 선택과 잠금 상태를 장르보다 우선한다.
- 별도 기본 PNG를 새 manifest·추가 migration으로 등록하고 장르별 초기/기본/선택 목록 조회를 연결한다. 적용된 migration은 수정하지 않는다.

내장 image_gen으로 PNG 25장을 개별 생성했다. 원본은 1536×1024이며 프롬프트·별칭·파일 경로·SHA를 색인에 기록했다. 원본과 구성표를 검사하고 갤러리 검증 결과는 `GALLERY_CHECK.json`에 남긴다. 실제 앱 코드 변경은 없어 앱 회귀 테스트를 실행하지 않았다.
