# 모바일 화면·조작 방식 검토 및 수정

검토일: 2026-09-06

사용자 요청: 화면 잘림과 줄바꿈뿐 아니라 PC 버튼·탭을 작은 화면에 적합한 선택 메뉴로 바꾸는 등 모바일 사용성을 수정한다.

## 범위와 기준

- `DESIGN.md` 전체와 `.omd/preferences.md`를 확인했다. 랜딩의 디자인 계약을 워크스페이스 전체에 확대하지 않고, 나머지 화면에는 저장소의 기존 Theme V2 토큰과 실제 기능 계약을 적용했다.
- Chromium 로컬 브라우저에서 320·390·430px 너비로 작품 선택, 원고, 분석 목록, 작품 설정 네 화면, 업로드, 리더, 두 후보 검토 화면을 순회했다. 랜딩·인증·공개 체험도 확인했다.
- 상세 입력은 320×568, 체험의 가로·세로 전환은 667×375와 320×375에서 확인했다. 랜딩 320px·200% 확대 검사는 기존 E2E로 검증했다.
- 보호 화면은 목 API·합성 계정/작품 데이터로 검토했다. 실제 작품을 생성·수정·삭제하지 않았다.

## 검증 결과

- `npm run build`: 통과. 기존 번들 크기 경고는 남아 있다.
- `npm run lint`: 오류 0, 기존 경고 39.
- 최신 `main` (`19df2f8`, 로고·Meta Pixel 반영)에 이번 변경만 옮긴 뒤 전체 E2E 194건을 검증했다. 최종 실행은 **192 통과, 2 생략** (Chromium, workers 4)이다.
- 최초 병렬 실행에서 기존 후보 연결 모달 테스트 1건이 시간 초과되었으나 추적 기록을 켠 단독 실행과 최종 전체 실행 모두 통과했다. 해당 테스트나 제품 동작은 변경하지 않았다.
- 기존 3000번 개발 서버와 분리한 3001번 Vite 서버에서 같은 Playwright 설정으로 실행했다. 임시 포트 설정은 커밋하지 않는다.
- 공개 체험 E2E는 진입 시 맨 위 유지·회전 시 불필요한 이동 없음·사용자 스크롤 유지·전체 시나리오 완료·초기화·회원가입 전환을 검증한다. 강조 대상이 항상 첫 화면에 보여야 한다는 기존 검증은 위에서부터 읽는 계약으로 바꿨다.
- 생략한 2건은 실제 Backend 주소와 인증 계정이 필요한 설정집·세계관 저장 연동 테스트다.
- Pencil JSON의 중복 ID·해결되지 않는 참조는 없고 추가 캡처 경로가 모두 존재한다. 활성 모바일 탐색 프레임 9개, 두 검토 필터와 실제 캡처 보드 `mobileUx20260906`을 동기화했다.

## 검증 한계

- 실제 iPhone/Android의 가상 키보드, Safari/WebKit, 운영 데이터 전체 조합은 검증하지 않았다. 실기기 검증 완료로 해석하지 않는다.
- 공개 법률 페이지의 런타임 본문은 이번 수동 순회에서 오류 상태 위주로 확인했으며, 게시 본문·인증 계약 회귀는 기존 E2E 범위다.
- 이번에 발견한 가림·가로 넘침·조작 밀도 문제는 수정했다. 이 문서는 모든 콘텐츠 조합의 접근성 인증이나 전체 디자인 시스템 적합성 판정이 아니다.
